# Bundled VulkanMod notice

This distribution includes the complete official VulkanMod 0.5.4 runtime for Minecraft 1.21.4 as a Fabric nested JAR.

- Upstream project: `xCollateral/VulkanMod`
- Pinned upstream tag: `0.5.4`
- Pinned upstream commit: `b416317b5d96f2ea3e3118fcaf22a91f40a5cb25`
- Upstream license: LGPL-3.0

The VulkanMod binary remains a separate nested JAR inside the SmoothGL install JAR, preserving its upstream mod identity and metadata. The SmoothGL Pulse compatibility layer is maintained separately around it.
